Routing Workflow

Classify an input first, then answer it with a prompt written for that category. This example shows the pattern with Spring AI and structured classifier output.

How it works

  • 1 · ClassifyThe model reads the input and picks one route, returning its reasoning and the chosen route name.
  • 2 · RouteThe router looks up that route in a map of specialized prompts. An unknown name fails fast.
  • 3 · AnswerThe input goes to the selected prompt, and that response is returned to the caller.

Core call

public String route(String input, Map<String, String> routes) {
    String routeKey = determineRoute(input, routes.keySet());
    String selectedPrompt = routes.get(routeKey);
    if (selectedPrompt == null) {
        throw new IllegalArgumentException("Selected route '" + routeKey + "' not found in routes map");
    }
    return chatClient.prompt(selectedPrompt + "\nInput: " + input).call().content();
}
